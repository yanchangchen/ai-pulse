## How to Use This List

- **Tier** = 1 (scan every run) / 2 (scan if keywords match) / 3 (deep reference)
- **Update Freq** = how often they publish meaningful posts
- **AI Signal** = ⭐⭐⭐ High / ⭐⭐ Medium / ⭐ Occasional
- **Focus Tags** = dominant technical themes
- Add blogs to your RSS reader (Feedly, Inoreader) grouped by Tier

## RSS Feed Setup

**Recommended RSS reader:** Feedly or Inoreader

**Suggested folder structure:**
```
📁 Tier 1 — Weekly Scan
  ├── AI Labs (Anthropic, OpenAI, DeepMind, Meta, HuggingFace)
  ├── Agent Frameworks (LangChain, LlamaIndex, W&B)
  └── Big Tech Cloud (AWS ML, Google Cloud AI, Azure AI, GitHub)

📁 Tier 2 — Keyword Filter
  ├── Big Tech Engineering (Netflix, Spotify, Uber, Stripe...)
  ├── Inference & Hardware (Modal, Together, Groq, vLLM...)
  ├── Security (Trail of Bits, Lakera, Protect AI...)
  └── Singapore & APAC (GovTech, Grab, Trust Bank...)

📁 Tier 3 — Deep Reference
  └── Academic & Research (Lilian Weng, Chris Olah, Distill...)
```

**Keyword filter for Tier 2:** Only read posts that contain at least one of: `agent`, `LLM`, `inference`, `fine-tuning`, `RAG`, `MCP`, `agentic`, `benchmark`, `evaluation`, `multimodal`
